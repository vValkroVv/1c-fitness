# 1c-fitness

Актуальный порядок переноса 20–21 сентября:
[единый план](docs/20260920_final_migration_plan.md).

Входная команда — `python3 scripts/run_fitbase_migration.py --help`.
Она готовит проверку/восстановление backup и запускает сборку XLSX с отдельным
архивом фотографий. Поддерживаются точные дата и время актуальности либо
смещение от BackupFinishDate; реальное время backup сохраняется отдельно.

[Журнал подготовки и репетиции](docs/20260920_final_migration_worklog.md).
