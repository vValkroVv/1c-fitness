# SQL discovery: owner-change source

Дата: `2026-06-22`

## Runtime

Discovery выполнялся через SQL Server 2022 контейнер `mssql-fitness-2022`,
куда attach-нута база `FitnessRestored_20260523_macos`.

## Найденный источник

Документ `Изменение условий членства, пакета услуг` хранится в:

```text
dbo._Document138
```

Табличная часть:

```text
dbo._Document138_VT776
```

Для найденных кейсов `56469` и `56501` табличная часть пустая; все нужные
ссылки находятся в заголовке `_Document138`.

## Поля

| Поле | Назначение |
| --- | --- |
| `_IDRRef` | ссылка документа изменения |
| `_Number` | номер документа |
| `_Date_Time` | дата документа с 1С-смещением +2000 лет |
| `_Posted` | проведен |
| `_Marked` | пометка удаления |
| `_Fld762RRef` | старый клиент (`Клиент`) |
| `_Fld767RRef` | новый владелец (`Владелец`) |
| `_Fld763RRef` | членство / документ `_Document163` |
| `_Fld764RRef` | модификатор; для членств `Смена владельца ` |
| `_Fld760RRef` | организация/клуб |

Точный фильтр модификатора:

```sql
LTRIM(RTRIM(modifier._Description)) = N'Смена владельца'
```

Это важно: простой `LIKE '%Смена владельца%'` захватывает еще
`Смена владельца подарочной карты`, что не является переносом членства.
