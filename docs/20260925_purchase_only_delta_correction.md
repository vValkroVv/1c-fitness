## Исправление ошибочных строк без покупки

Предыдущая версия файла абонементов содержала 28 клиентских строк с пустым договором. Они были добавлены для формального покрытия всех 72 новых и 31 прежнего клиента. Это не новые покупки; пользователь указал исключить их из файла импорта. В актуальном XLSX 213 строк, у каждой заполнен уникальный номер реального договора. Пятнадцать заявок без покупки не передаются. Ранее подготовленные файлы с 72 заявками и 241 строкой абонементов больше не являются актуальной поставкой.
