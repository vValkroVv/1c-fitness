Поиск только по фамилии в обоих случаях показал других людей, а не выбранные карточки. Это выборочная проверка двух клиентов. Для первого клиента архив заявок отдельно не включался; поиск по телефону в UI не проводился. Поэтому результат не доказывает отсутствие совпадений во всей базе Fitbase. Основа защиты от повторов остаётся в проверках исходных ID и телефонов относительно прежних поставок.
