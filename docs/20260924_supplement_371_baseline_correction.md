# Учёт дополнения 371 клиента в дельте от 23 сентября

> Актуальный состав дельты после изменений 25.09.2026 см. в [итоговом исправлении](20260925_purchase_only_delta_correction.md). Количества ниже отражают исторические этапы подготовки.

## Исправление базы сравнения

Первая сборка дельты сравнивала backup 23.09.2026 с основным комплектом из
backup 20.09.2026 и не читала отдельную поставку 371 клиента. После
уточнения база проверки повторов включает оба подготовленных комплекта:

- основной комплект `output/20260922_fitbase_for_customer/`, срез
  `2026-09-22 20:12:12`;
- дополнение `output/20260921_phone_dedup_supplement_371/`, срез
  `2026-09-21 20:12:12`: 371 заявка, 879 строк абонементов, 10 услуг.

Оба комплекта созданы из backup с фактическим `BackupFinishDate`
`2026-09-20 20:12:12`. Граница новых операций осталась этим фактическим
временем; сдвинутые срезы старых файлов на неё не влияют.

## Сверка файлов

На момент этой сверки в дельте было 103 заявки, 213 абонементов и 51 услуга;
совпадений по исходным ID с файлами дополнения 371 клиента не было. Позднее
31 заявку исключили: эти покупатели уже есть в Fitbase как «отказники».
Актуальные файлы содержат 72 заявки, 213 новых покупок абонементов и 51
покупку услуг в двух XLSX. К абонементам добавлены 28 клиентских строк без
новой покупки, поэтому в этом XLSX теперь 241 строка.
Актуальные контрольные суммы указаны в `docs/20260924_delta_imports_worklog.md`.
Один телефон совпадает у разных клиентов
(`000018782` и `000040842`); записи не объединены по телефону. Построчные
проверки: `output/20260923_delta_from_20260920/reports/imports/supplement_baseline_audit.json`
и соседние CSV.

Отдельный файл оплат рассрочек пересчитан по обоим старым комплектам. В нём
1 242 договора, в том числе три из дополнения 371 клиента. Семь выявленных
движений оплаты на 31 972 ₽ не изменились. Источник каждого старого договора
и соответствующий прежний срез теперь указаны в XLSX. Расчёт и ограничения:
`docs/20260924_delta_installments_worklog.md`.

## Состояние Fitbase

Подготовка дополнения не включала его загрузку в Fitbase. Прежние журналы
подтверждают загрузку основного комплекта, но не отдельного XLSX дополнения.
В полном снимке API Fitbase от 23.09.2026 можно достаточно уверенно связать
339 из 371 исходных клиентов с карточками по ФИО, телефону и в части случаев
карте. Для 32 клиентов связь не установлена. В API нет исходного `client_id`,
а общий телефон не определяет личность; присутствие карточки не устанавливает
факт загрузки именно дополнительного пакета и полноту его абонементов и услуг.
Источник снимка: `output/20260923_fitbase_photo_audit/api_snapshot_metadata.json`;
контекст: `docs/20260923_fitbase_photo_supplement_371_audit.md` и
`docs/20260922_fitbase_live_audit_checkpoint.md`.
