## Подключение SQL

Python TDS через опубликованный Docker-порт `127.0.0.1:11434` повторяет timeout
на prelogin. Проверены обычное имя localhost и отключение шифрования login:
оба варианта дали тот же timeout. SQLCMD внутри контейнера работает.
Причина опубликованного порта пока не установлена.

Для обхода добавлен `scripts/docker_sql_bridge.py`: локальный TCP-порт 11435
передаёт неизменённые двоичные данные через `docker exec -i` к SQL 1433 внутри
того же контейнера. Пароли мосту не передаются. Сетевые/VPN-настройки, исходные
базы и SQL-параметры не меняются. Шифрование login в pipeline остаётся включено.
Работоспособность моста проверяется до запуска подготовки.

Проверка моста прошла: Python TDS с включённым шифрованием login выполнил
SELECT состояния обеих баз, обе ONLINE. Запущен полный новый прогон:

```bash
python3 scripts/docker_sql_bridge.py
python3 scripts/run_fitbase_migration.py \
  --backup-file data/Fitnes-20-09-26.fast.bak \
  --backup-sql-path /backup/Fitnes-20-09-26.fast.bak \
  --database FitnessRestored_20260630_macos \
  --run-name 20260921_final \
  --effective-offset-days 1 --port 11435 --use-existing
```

Общий лог: `logs/20260921_final_run.log`. Базы не восстанавливаются повторно.
Прежний порт 11434 в инструкции заменён только явным параметром этого прогона.

1 520 000 байт; SHA2_256 на стороне SQL совпал с SHA-256 полученных Python байт.

## Остановка на канонизации шаблонов

Первый прогон корректно остановился на `membership_xlsx_build`; READY не
создан. Полная диагностика нашла семь конфликтов, сохранённых в
`logs/20260921_template_source_conflicts.json`:

- у четырёх ранее закреплённых шаблонов изменились индивидуальные параметры
  старого контрольного договора: израсходованная заморозка или срок;
- у двух прежде одновариантных шаблонов рассрочки появились дополнительные
  цены/сроки;
- ещё один продукт рассрочки переименован в исходной 1С. Его ID и код
  `00000001753` сохранились, поэтому это прежний продукт.

Для всех семи найдены параметры в принятой июньской поставке. Сохраняются
именно эти параметры шаблонов; цены, оплаты, сроки и остатки отдельных
сентябрьских договоров этим решением не меняются. Историческое сохранение
задаётся явным флагом только для четырёх проверенных решений, с audit-записью.
Три новых конфликта получают явные строки CSV с прежними принятыми значениями.
Неизвестные конфликты по-прежнему останавливают сборку.

Три контрольных договора подтверждены в обоих backup:
`00000151391` (МУЛЬТИКАРТА рассрочка: 14 990 / 12 месяцев),
