## Что сохранено

Все **семь XLSX и фотоархив побайтно совпадают**. Все 766 клиентов остаются
в заявках. История не была добавлена в основной файл абонементов, поэтому
изменение касается только сопровождающего отчёта, без пересчёта данных.
Срез обоих комплектов: `2026-09-21 20:12:12`.

36 оставшихся файлов побайтно совпадают с исходными. В трёх текстовых файлах
обновлены сведения о составе: `README.md`, `reports/business_notes.md`,
`reports/final_report.md`. Убраны обещания приложенной истории, изменены
пути нового варианта и сохранены известные открытые вопросы по договорам
154220 и 144499. Уточнено, что договор 151350 на текущем срезе завершён.
Новых файлов внутри второго комплекта не добавлено.

Фотоотчёт `_reports/excluded_clients.csv` внутри ZIP с JPEG остаётся на месте.
Он описывает исключения фотографий по телефону, изображению или составу
заявок и не является отчётом об исключённой договорной истории.

## Воспроизведение

Для новых свободных путей, заданных в скрипте:

```bash
python3 scripts/create_delivery_without_excluded_history.py
python3 scripts/package_fitbase_delivery.py \
  --delivery output/20260921_final_v2_delivery_without_excluded_history \
  --output output/20260921_fitbase_customer_delivery_without_excluded_history.zip
```

Скрипты отказываются перезаписывать существующий вариант. SQL, исходная
поставка и восстановленные базы при создании этой копии не изменялись.
