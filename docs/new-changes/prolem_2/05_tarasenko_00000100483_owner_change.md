## Масштаб проблемы

В 1С на cutoff есть два релевантных модификатора:

| Модификатор | Документов | Уникальных членств | Период |
| --- | ---: | ---: | --- |
| `Смена владельца подарочной карты` | `3 771` | `3 688` | `2019-03-11` - `2026-04-24` |
| `Смена владельца` | `781` | `746` | `2023-01-17` - `2026-05-23` |

Impact по текущему `membership_import_facts`, если latest owner-change считать
по обоим модификаторам:

| Метрика | Кол-во |
| --- | ---: |
| строк с owner-change любого из двух типов | `4 192` |
| строк, где effective owner изменился бы | `668` |
| из них новый владелец есть в финальном import_заявки | `668` |
| новый владелец вне финального import_заявки | `0` |

Все `668` изменяемых строк приходятся на latest-модификатор
`Смена владельца подарочной карты`.

## Нужно решить/исправить

Решение: считать оба модификатора как смену владельца:

```sql
LTRIM(RTRIM(modifier._Description)) IN (
    N'Смена владельца',
    N'Смена владельца подарочной карты'
)
```
