## Предварительные автоматические признаки

Для поиска таких лишних продаж в группе `327` можно использовать каскад:

1. `price > 0`;
2. `matched_payment_ref IS NULL`;
3. `is_full_subscription = 1`;
4. строка активна по cutoff;
5. status в `Контакт с клиентом`, `Отказ`, `Бронь абонемента`;
6. у клиента есть другой active full-абонемент;
7. другой active full имеет прямой платеж или посещения;
8. у подозрительной строки нет посещений.

Самые безопасные для ручной проверки в первую очередь:

- `67` активных строк `D_positive_no_payment_cash_327`, где у клиента есть
  другой active full;
- внутри них особенно статусы `Контакт с клиентом`, `Отказ`, `Бронь абонемента`;
- отдельно дубли с одинаковыми/почти одинаковыми датами и одинаковыми названиями,
  потому что в примерах SQL уже есть пары похожих продаж.

## Что пока нельзя утверждать автоматически

Нельзя просто удалить все `327` строк:

- часть строк имеет статус blank или `Успех`;
- часть может быть реальной оплатой наличными без корректного платежного
  документа;
- в группе есть trial/guest строки, их нужно разбирать отдельно.

Нельзя считать `_Marked=0x01` обязательным признаком лишней продажи:

- в backup `00000145048` еще `_Marked=0x00`;
- менеджер сказала, что удалила продажу во время проверки, то есть это могло
  произойти уже после даты backup.

## Решение 2026-06-24: строгий active + later `Контакт с клиентом` исключаем

Кейс закрыт в основном пайплайне абонементов.

Добавлено воспроизводимое правило:

> Если у клиента есть full-абонемент, активный на cutoff
> `2026-05-25 08:00`, и есть следующий/later full-абонемент этого же клиента
> в статусе `Контакт с клиентом`, то later-строку не переносим в
> `Импорт_абонементы_клиентов.xlsx`.

Техническое определение later-строки:

- строка является full-абонементом, не trial/guest и не субарендой;
- `status = Контакт с клиентом`;
- `sale_date >= sale_date` текущего активного full-абонемента;
- `start_date >= start_date` текущего активного full-абонемента;
- `end_date >= cutoff`;
- у этого же клиента есть другой full-абонемент, активный на cutoff.

Почему правило безопасное:

- это ровно тот паттерн, который бизнес подтвердил на Поповой как
  лишнюю/неудаленную продажу;
