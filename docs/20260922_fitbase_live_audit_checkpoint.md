  успешному появлению файла. Проверять фактический файл, не запускать копии
  одной выгрузки только из-за таймаута.
- После некоторых действий DOM сразу возвращал старое состояние до завершения

  обновлённым фильтром, строками и счётчиком.

- `locator.evaluate()` на dialog несколько раз зависал. Чтение видимых
