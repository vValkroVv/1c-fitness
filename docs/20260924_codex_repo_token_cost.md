## Расчёт стоимости

Использованы стандартные тарифы OpenAI API на 24.09.2026, USD за 1 млн
токенов: GPT-5.5 — вход 5 / кэш 0,5 / выход 30;
GPT-5.6 Sol — 4 / 0,4 / 20; GPT-6 Astra — 10 / 1 / 50;
GPT-6 Sol — 2 / 0,2 / 10; GPT-6 Luna — 0,1 / 0,01 / 0,5.
Источники: [GPT-5.5](https://developers.openai.com/api/docs/models/gpt-5.5),
[GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol),
[GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra),
[GPT-6 Sol](https://developers.openai.com/api/docs/models/gpt-6-sol),
[GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna).

Формула для обычного запроса: `(вход − кэш) × тариф входа + кэш × тариф кэша
+ выход × тариф выхода`, всё делится на 1 млн. Для зарегистрированных
запросов с входом свыше 272 тыс. токенов вход и кэш умножены на 2, выход —
на 1,5 согласно страницам моделей. Без этой надбавки оценка — 1 010,05 USD;
надбавка — 59,04 USD. Записей о платной записи в кэш нет.

Это эквивалент стоимости токенов через API, не выписка о фактическом платеже
за Codex. Тарифы взяты на дату расчёта, а не по историческим датам запросов.
Платные вызовы инструментов, региональные надбавки и налоги не учтены.
Для 303 042 токенов в логах есть общий счётчик, но нет разбивки на вход и
выход; они входят в общий объём, но не в сумму 1 069,09 USD. Даже если все
эти токены считать дорогим выходом с надбавкой за длинный контекст,
дополнительная стоимость составила бы не более 10,57 USD.

## Метод и проверка

Команда повторного подсчёта:

```bash
python3 scripts/calculate_codex_repo_usage.py
```

По каждой логической сессии накопленные `token_count` переведены в приращения.
Для первого события дочерней сессии взят `last_token_usage`, поскольку
накопленный счётчик может уже включать токены родителя. Повторные события
с неизменившимся накопленным счётчиком пропущены. Найдено 22 случая
унаследованного первого счётчика, 353 повтора и 2 перезапуска счётчика.
Скрипт прошёл `python3 -m py_compile` и завершил подсчёт без ошибочных строк JSON.
