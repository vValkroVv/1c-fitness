## Откуда правило

1. Исходный task-desc/fitness_updated_restore_to_fitbase_plan.md, раздел 14, строки 948–1007: совпадение только ФИО + полного набора телефонов; одинаковые телефоны при разных ФИО — спорные случаи для отчёта, без молчаливого склеивания.
2. docs/step_26_part2_20260525_phone_deduplication.md, строки 5–13: записан более поздний комментарий заказчика от 24.05.2026 18:02–18:03: «Вообще по номеру телефону должен остаться один клиент с самым свежим приобретенным абонементом».
3. Этот документ фиксирует переход к удалению по телефону без проверки ФИО. Git содержит коммит c24c90b от 24.05.2026 с сообщением Apply phone dedupe to May 25 Fitbase exports.
4. В end-to-end-xlsx/scripts/run_pipeline.py:627 параметр --dedupe-by-phone-keep-latest-subscription включён в стандартный запуск. Реализация — scripts/17_build_part2_combined_xlsx.py:132 и :165 внутри end-to-end-xlsx.

Прямое исходное сообщение переписки в просмотренных локальных документах не найдено. Авторство и время подтверждаются записью в проектном журнале, а не независимо проверенной перепиской. В репозитории одновременно сохранены исходное правило ФИО + телефон и более позднее правило только по телефону; текущий код применяет второе.
