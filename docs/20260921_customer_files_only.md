# Компактный комплект для заказчика

По уточнению пользователя подготовлен пакет только с передаваемыми данными:

- Папка: `output/20260921_fitbase_for_customer/`.
- ZIP: `output/20260921_fitbase_for_customer.zip`.
- Состав: ровно 8 файлов, семь XLSX и один архив фотографий.

Семь XLSX содержат заявки, карты, абонементы, шаблоны абонементов, услуги,
шаблоны услуг и отдельный договор 151350. Фотоархив сохранён в принятом виде,
включая соответствие JPEG клиентам и встроенные инструкции к фотографиям.

Внешний ZIP и папка не содержат отчётов pipeline, настроек, READY,
дополнительной истории 1 806 договоров или технических протоколов.
Предыдущие полные варианты сохранены отдельно для аудита.

Все восемь файлов побайтно совпали с проверенными файлами исходной поставки.
Проверены точный состав папки и ZIP, размеры, SHA-256 и CRC всех вложений.
Результат PASS. Размер ZIP: 862 912 269 байт.
SHA-256: `2608e628be241b71b47762af27f53fc6347dadb67bfa5741bdcd523722c81ee8`.

Воспроизводимый сборщик: `scripts/package_fitbase_customer_files.py`.
Протокол: `logs/20260921_customer_files_only.json`.

Создание компактного комплекта не меняет данные договоров. Ранее выявленные
вопросы по остатку посещений 154220 и сроку 144499 остаются открытыми.
