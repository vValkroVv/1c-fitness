Расскажу чуть подробнее, что нужно в выгрузке.

В наши шаблоны с продажами абонементов (шаблоны с названиями "импорт_абонементы_клиентов" для переноса требуются следующие данные:

1 ФИО клиента
2 Номер телефона (при наличии возможности выгрузки)
3 Номер карты
3 Название абонемента
4 Дата продажи
5 Дата активации
6 Дата окончания
7 ( только для продаж абонементов) Остаток дней для заморозки
8 ( только для продаж абонементов) Остаток гостевых визитов
9 Остаток посещений в абонементе/услуге(только для абонемента-субаренда)
10 Стоимость
11 Сумма долга
12 Способ оплаты
13 Менеджер продажи(как ты для заявок делал)

Для переноса шаблонов абонементов  (файлы "Импорт_шаблоны_абонементов" требуются следующие данные:

1 Название абонемента
2 Стоимость
3 Срок действия (для шаблонов абонементов может быть указан, как в днях, так и в месяцах)
4 ( только для шаблонов абонементов) Тип действия (месяцев или дней)
5 Количество доступных посещений в абонементе(только для абонемента субаренда)


К Импорт_шаблоны_абонементов.xlsx таблице добавь еще столбец-доступ к филиалам.
