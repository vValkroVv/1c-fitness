## Как читать форматы и результаты

XLSX содержат данные для импорта; договор problem4 сохранён отдельно по плану. MD и TXT содержат пояснения для человека. JSON сохраняют результаты проверок и доказательства в форме, удобной для программ. CSV используются для построчных отчётов или явных правил шаблонов. YML фиксируют настройки запуска и назначения менеджеров.

В некоторых исходных отчётах есть ссылки на SQL, логи, скрипты и подробные доказательства вне пакета. Такие ссылки относятся к рабочему репозиторию; перечисленные внешние материалы в эти 43 файла не входят. Эта опись создана отдельно в `docs/` и также не добавлена в первый пакет.
