# SQL discovery: owner-change source

Дата: `2026-06-22`

## Runtime

Discovery выполнялся через SQL Server 2022 контейнер `mssql-fitness-2022`,
куда attach-нута база `FitnessRestored_20260523_macos`.

## Найденный источник

Документ `Изменение условий членства, пакета услуг` хранится в:

```text
dbo._Document138
```

Табличная часть:

```text
dbo._Document138_VT776
```

Для найденных кейсов `56469` и `56501` табличная часть пустая; все нужные
ссылки находятся в заголовке `_Document138`.

## Поля

| Поле | Назначение |
| --- | --- |
| `_IDRRef` | ссылка документа изменения |
| `_Number` | номер документа |
| `_Date_Time` | дата документа с 1С-смещением +2000 лет |
| `_Posted` | проведен |
| `_Marked` | пометка удаления |
| `_Fld762RRef` | старый клиент (`Клиент`) |
| `_Fld767RRef` | новый владелец (`Владелец`) |
| `_Fld763RRef` | членство / документ `_Document163` |
| `_Fld764RRef` | модификатор; для членств `Смена владельца ` или `Смена владельца подарочной карты` |
| `_Fld760RRef` | организация/клуб |

Точный фильтр модификатора после correction `2026-06-23`:

```sql
LTRIM(RTRIM(modifier._Description)) IN (
    N'Смена владельца',
    N'Смена владельца подарочной карты'
)
```

Старое допущение, что `Смена владельца подарочной карты` не является переносом
членства, отменено ниже.

## Correction 2026-06-23

Старое допущение оказалось неверным для части членств.

При проверке абонемента `00000100483` у Тарасенко Александра Сергеевича
найдено, что `Смена владельца подарочной карты`:

- ссылается на тот же документ членства `_Document163`;
- меняет старого/нового клиента в `_Document138`;
- подтверждается последующими посещениями `_Document150` уже по новому
  клиенту.

Конкретная цепочка:

| Документ | Дата | Старый клиент | Новый клиент | Модификатор |
| --- | --- | --- | --- | --- |
| `00000041053` | `2023-02-01 16:46:09` | Ли Сергей Вячеславович | Тарасенко Александр Сергеевич | `Смена владельца` |
| `00000041452` | `2023-03-10 09:07:54` | Тарасенко Александр Сергеевич | Коновалов Никита Витальевич | `Смена владельца подарочной карты` |

Impact по текущему `membership_import_facts`: если latest owner-change считать
по двум модификаторам (`Смена владельца`, `Смена владельца подарочной карты`),
то `668` строк меняют effective owner; во всех `668` случаях новый владелец
есть в финальном `import_заявки`.

Подробности: `docs/new-changes/prolem_2/05_tarasenko_00000100483_owner_change.md`.

Реализация обновлена `2026-06-23` в
`sql/part2_03_build_three_funnel_staging.sql`: оба модификатора включены в
основной owner-change фильтр. Основные XLSX абонементов пересобраны, test
representative XLSX намеренно не пересобирался.
